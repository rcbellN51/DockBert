# Haiku Current Port

This branch contains updates to DockBert developed and tested on current Haiku.
The work includes compatibility fixes for current Haiku, along with additional
functionality and refinements. Much of this work was developed through iterative
AI-assisted development with ChatGPT, with the resulting code built, tested,
debugged, and validated on a Haiku system.

## Application icon

The DockBert application icon is derived from the Deskbar icon and the
Printers checkmark icon included with Haiku. The original Haiku artwork
is distributed under the MIT license.

The two icons were combined and adjusted in Icon-O-Matic to preserve
DockBert's traditional Deskbar-with-checkmark design while providing a
native HVIF application icon.

Source: https://github.com/haiku/haiku
